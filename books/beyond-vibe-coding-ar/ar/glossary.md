# معجم الدفعة الأولى

> **إضافة تعليمية من الإعداد العربي.** هذه تعريفات تمهيدية مرتبطة بالمقدمة والفصل الأول،
> وليست تعريفات معيارية تستوعب كل الحالات. نلتزم بهذه المقابلات في الدفعات اللاحقة، ونوثّق
> أي تغيير اصطلاحي بدل تبديل الكلمات بصمت.

## النهجان والمفاهيم المركزية

| المصطلح الإنجليزي | المقابل العربي | المعنى في هذا الكتاب |
| --- | --- | --- |
| Vibe coding | «فايب كودينغ» | نهج استكشافي يبدأ بالتوجيه: تصف ما تريد بلغة طبيعية وتدع النموذج يملأ الفراغات؛ نُبقي اللفظ منقولًا لأنه مصطلح حديث متداول، ونشرحه عند أول ظهور. |
| AI-assisted engineering | الهندسة المُعانة بالذكاء الاصطناعي | طريقة منضبطة تدخل الذكاء في كل مرحلة من التطوير ضمن خطة وقيود واضحة؛ «خطة أولًا» مقابل «توجيه أولًا». |
| Programming with intent | البرمجة بالقصد | التعبير عن الهدف (ماذا) بلغة عالية المستوى وترك الذكاء يستنتج التنفيذ (كيف). |
| Prompt | توجيه (برومبت) | الوصف أو السؤال الذي يُدخل إلى نظام ترميز ذكي؛ نلتزم «توجيه» بعد ذكر الأصل مرة. |
| Prompt engineering | هندسة التوجيه | مهارة صياغة توجيهات واضحة محددة للحصول على ناتج أدق. |
| Large language model / LLM | نموذج لغوي كبير | نموذج بمليارات البارامترات درُب على نصوص وشيفرة هائلة ليولّد نصًا وشيفرة مرجحة. |
| Intent | القصد | ما يريد المطوّر إنجازه، معبَّرًا عنه عالي المستوى. |
| Context window | نافذة السياق | قدر النص/الشيفرة الذي يحيط به النموذج ويفهمه دفعة واحدة؛ أطولها يتيح فهم مشاريع كاملة. |
| Token | رمز | قطعة كلمة أو رمز شيفرة يولدها النموذج واحدة واحدة. |
| Hallucination | هلوسة | توليد النموذج دوالًا أو واجهات غير موجودة تبدو معقولة. |
| Boilerplate | شيفرة نمطية | شيفرة إعداد متكررة قليلة الخصوصية يبرع الذكاء في توليدها. |
| Codebase | قاعدة الشيفرة | كامل شيفرة المشروع وملفاته التي تفهرسها الأدوات الذكية. |
| Diff | فرق التغييرات | عرض التعديلات المقترحة لاعتمادها أو رفضها. |
| MVP | الحد الأدنى القابل للتطبيق | أول نسخة من منتج تحقق الفكرة وتُختبر بها. |
| Zero to one | من الصفر إلى الواحد | إنشاء شيء جديد كليًا لا تطوير قائم. |
| CRUD | عمليات CRUD | إنشاء وقراءة وتحديث وحذف؛ العمل الصيغي الشائع في تطبيقات الأعمال. |
| SDLC | دورة حياة تطوير البرمجيات | مراحل التطوير من التصميم إلى الاختبار والنشر. |
| AI pair programmer | مبرمج زوجي ذكي | تشبيه المساعد الذكي بشريك برمجة يجاورك. |
| Knowledge paradox | مفارقة المعرفة | الذكاء يسرّع الخبير أكثر من المبتدئ؛ الخبير يسرّع ما يعرفه والمبتدئ يحاول التعلم به. |
| The 70% problem | مشكلة السبعين بالمئة | الذكاء يقطع معظم الطريق سريعًا لكن الـ 30% الأخيرة من الصحة عسيرة. |

## الأدوات والبروتوكولات

| المصطلح الإنجليزي | المقابل العربي | المعنى في هذا الكتاب |
| --- | --- | --- |
| VSCode | VSCode | محرر الشيفرة الأشهر؛ منصة مايكروسوفت بعد تكامل Copilot. يُترك باللاتينية. |
| GitHub Copilot | GitHub Copilot | مساعد الترميز المدمج في VSCode: إكمال مضمّن، محادثة، ووضع وكيل. |
| Agent mode | وضع الوكيل | نمط يستدعي أدوات وينفذ خطوات ذاتيًا حتى اكتمال المهمة، بمراجعة بشرية. |
| MCP | بروتوكول سياق النموذج (MCP) | طريقة معيارية تكتشف بها النماذج أدوات وبيانات خارجية وتتفاعل معها. |
| Cline | Cline | إضافة مفتوحة المصدر تحول VSCode إلى وكيل ترميز مستقل (Claude Dev سابقًا). |
| Cursor | Cursor | محرر «ذكاء أولًا» (تفريعة VSCode) بمحادثة ووضع Composer. |
| Composer | وضع الملحن (Composer) | نمط في Cursor لتوليد شيفرة متعدد الخطوات. |
| Windsurf | Windsurf | بيئة تطوير بفهرسة كاملة لقاعدة الشيفرة وتوليد معزز بالاسترجاع. |
| Cascade | واجهة Cascade | المحادثة الفائقة في Windsurf ذات السياق الأوسع. |
| Write mode | وضع الكتابة | نمط يطبق التغييرات على الملفات مباشرة بدل اقتراح فروق. |
| RAG | التوليد المعزز بالاسترجاع (RAG) | استرجاع أجزاء الشيفرة ذات الصلة وتغذيتها للنموذج سياقًا. |
| Artifacts | ميزة Artifacts | مساحة عمل في Claude تُعرض فيها الشيفرة وتُحرر وتُعاين لحظيًا. |
| Ollama | Ollama | وسيلة تشغيل نماذج محلية تدعمها أدوات مثل Cline. |
