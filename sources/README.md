# `sources/` — الأصول بلغتها الأم

هذا هو المكان **الوحيد** المخصص لملفات الكتب الأصلية كما صدرت، بلغتها الأم، دون أي
تعديل. لا تُترجم الملفات هنا ولا تُحرَّر ولا تُعاد تسميتها. كل ملف أصل له مجلد مستقل
ومعه `source.json` يسجّل بياناته وبصمته.

## القاعدة

| العنصر | القاعدة |
| --- | --- |
| اسم مجلد الأصل | `sources/<slug>-<edition>-<lang>/` بأحرف لاتينية صغيرة وشرطات، مثل `how-linux-works-2nd-en` |
| ملف الأصل | يُحفظ باسمه الأصلي الذي صدر به، دون تغيير |
| `source.json` | إلزامي لكل أصل: العنوان، المؤلف، الناشر، الطبعة، اللغة، عدد الصفحات، `sha256`، وحالة الحقوق |
| التعديل | ممنوع. إن احتجت نسخة معالجة (نص مستخرج، تحويل صيغة) فضعها في `build/` المستثنى من Git، لا هنا |
| الإحالة | كل مشروع ترجمة يشير إلى أصله عبر `source.dir` و`source.file` في `manifest.json` الخاص به |

## لماذا مجلد مستقل لكل أصل؟

- قد يُترجم الكتاب الواحد أكثر من مرة (طبعات مختلفة، أو لغات مختلفة)، وقد يشترك أصل
  واحد بين أكثر من مشروع. فصل الأصل عن المشروع يمنع تكرار الملفات الضخمة ويجعل
  البصمة مرجعًا واحدًا.
- `scripts/build_book.py --verify-source` يتحقق من بصمة الأصل وعدد صفحاته قبل أي بناء،
  فلا يمكن أن تُبنى نسخة عربية على أصل تغيّر بصمت.

## الحقوق — اقرأ هذا قبل إضافة أي أصل

المستودع **عام**. رفع كتاب محمي بحقوق نشر إلى مستودع عام هو إعادة نشر، وملكية الحقوق
تبقى لأصحابها؛ وجود الملف هنا لا يمنح إذنًا بالترجمة أو التوزيع. راجع
[docs/method/05-source-and-rights.md](../docs/method/05-source-and-rights.md) قبل إضافة
أصل جديد، وسجّل حالة الحقوق في `source.json` بحقل `rights.status`.
