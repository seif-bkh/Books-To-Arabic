# معجم الدفعة الأولى

> **إضافة تعليمية من الإعداد العربي.** هذه تعريفات تمهيدية مرتبطة بالفصل الأول، وليست تعريفات معيارية تستوعب كل الحالات. نلتزم بهذه المقابلات في الدفعات اللاحقة، ونوثّق أي تغيير اصطلاحي بدل تبديل الكلمات بصمت.

## النظام والتنفيذ

| المصطلح الإنجليزي | المقابل العربي | المعنى في هذا الكتاب |
| --- | --- | --- |
| Abstraction | التجريد | التركيز على الوظيفة والعلاقات مع إرجاء تفاصيل لا يحتاج إليها السؤال الحالي. |
| Component | مكوّن | جزء من النظام يمكن وصف وظيفته وواجهاته مع الأجزاء الأخرى. |
| Layer | طبقة | مجموعة مكونات عند مستوى مناسب من التجريد؛ ليست كل طبقة حدًا أمنيًا. |
| Hardware | العتاد | الأجزاء المادية للحاسوب وأجهزته. |
| Operating system | نظام التشغيل | المنظومة التي تدير الموارد وتقدم بيئة وخدمات لتشغيل البرامج؛ نحدد نطاق المقصود بحسب السياق. |
| Distribution | توزيعة | تجميع للنواة والأدوات والمكتبات والخدمات، مع وسائل لتثبيتها وإدارتها. |
| Kernel | النواة | المكوّن المركزي الذي ينظم موارد النظام ويقدم واجهات محمية للعمليات. |
| CPU | وحدة المعالجة المركزية؛ المعالج | العتاد الذي ينفذ التعليمات. |
| CPU core | نواة معالجة | وحدة تنفيذ داخل المعالج؛ ليست نواة نظام التشغيل. |
| Logical CPU | معالج منطقي | مورد تنفيذ تراه النواة وتستطيع إسناد مهمة إليه؛ لا يساوي بالضرورة نواة مادية مستقلة. |
| Program | برنامج | تعليمات وبيانات معدّة للتنفيذ، وغالبًا تكون محفوظة في ملف. |
| Process | عملية | مثيل جارٍ من تنفيذ برنامج، له حالة وموارد ومعرّف. |
| Process ID / PID | معرّف العملية | رقم يميز العملية ضمن فضاء معرّفات العمليات الذي نلاحظها فيه. |
| Parent process | العملية الأم | العملية المرتبطة بعلاقة الأبوة بعملية ابنة؛ نستخدم نموذج الإنشاء المعتاد في هذا الفصل. |
| Child process | العملية الابنة | العملية الناتجة عن الإنشاء في نموذج الأم والابنة. |
| Thread | خيط تنفيذ | مسار تنفيذ داخل عملية؛ تشترك خيوط العملية في مساحة عناوينها. |
| Scheduling | الجدولة | اختيار المهام التي تعمل وتوقيت إتاحة المعالج لها وفق سياسة النظام. |
| Context switch | تبديل السياق | حفظ ما يلزم من سياق تنفيذ واستعادة سياق آخر لمتابعة مهمة مختلفة. |
| Time slice | شريحة زمنية | حصة زمنية في النموذج المبسط لتقاسم المعالج؛ ليست مدة ثابتة موحدة لكل المهام. |
| Concurrency | التزامن | تقدم أعمال متعددة خلال فترة واحدة، ولو بالتناوب. |
| Parallelism | التوازي | تنفيذ أعمال متعددة في الوقت نفسه على موارد تنفيذ متعددة. |
| Interrupt | مقاطعة | حدث يستدعي معالجة خاصة، مثل حدث مؤقت أو إشارة من جهاز. |

## الذاكرة والواجهات والصلاحيات

| المصطلح الإنجليزي | المقابل العربي | المعنى في هذا الكتاب |
| --- | --- | --- |
| Main memory / RAM | الذاكرة الرئيسية | الذاكرة التي تحتوي على التعليمات والبيانات اللازمة للعمل الجاري؛ وهي متطايرة عادة. |
| Persistent storage | التخزين الدائم | وسيط يحتفظ بالبيانات دون الاعتماد على بقاء الجهاز قيد التشغيل، مثل قرص التخزين. |
| Bit | بت | وحدة ثنائية تأخذ القيمة صفر أو واحد. |
| State | حالة | وصف مكوّن أو نظام عند لحظة معينة، على مستوى تفصيل نحدده. |
| Process image | صورة العملية | تمثيل البرنامج وبياناته في الذاكرة؛ ليست صورة رسومية. |
| Address space | فضاء العناوين | مجموعة العناوين التي يمكن تفسيرها في سياق عملية أو بيئة معينة. |
| Virtual memory | الذاكرة الافتراضية | نموذج يفصل العناوين التي يستخدمها البرنامج عن ترتيب الذاكرة المادي ويتيح تنظيمها وحمايتها. |
| MMU | وحدة إدارة الذاكرة | عتاد يساعد على ترجمة العناوين وتطبيق حماية الذاكرة. |
| Page table | جدول الصفحات | بنية تديرها النواة لوصف خرائط صفحات الذاكرة وخصائص الوصول إليها. |
| Swap | مساحة المبادلة؛ المبادلة | تخزين مساند يمكن استخدامه لبعض صفحات الذاكرة؛ ليس هو الذاكرة الافتراضية كلها. |
| Copy-on-Write | النسخ عند الكتابة | مشاركة مادية مؤقتة لصفحات، مع إنشاء نسخة مستقلة عندما تتطلب الكتابة ذلك. |
| User mode | نمط المستخدم | نمط تنفيذ محدود الامتياز لتعليمات برامج المستخدم. |
| Kernel mode | نمط النواة | نمط تنفيذ يتيح تعليمات وعمليات ذات امتياز لإدارة النظام. |
| User space / userland | فضاء المستخدم | بيئة عمليات المستخدم ومجالات ذاكرتها، بما فيها كثير من الخدمات الخلفية. |
| Kernel space | فضاء النواة | مجال الذاكرة المحمي الخاص بالنواة. |
| Device driver | برنامج تشغيل جهاز | برمجيات تعرف تفاصيل التعامل مع جهاز وتدمجه في واجهات النظام. |
| System call / syscall | نداء نظام | واجهة تطلب عبرها عملية خدمة من النواة. |
| Pseudo-device | جهاز زائف | واجهة برمجية شبيهة بواجهة جهاز، دون اشتراط وجود عتاد مستقل يقابلها. |
| User / UID | مستخدم / معرّف المستخدم | هوية ومرجع رقمي يستعملهما النظام في بيانات الاعتماد وقرارات الصلاحيات. |
| Superuser / root | المستخدم ذو الصلاحيات العليا | الحساب الإداري التقليدي ذو المعرّف صفر؛ ليس نواة النظام. |
| Group / GID | مجموعة / معرّف المجموعة | هوية جماعية تساعد على تنظيم أذونات الوصول والمشاركة. |
| Permissions | أذونات الوصول؛ الصلاحيات | قواعد تحدد العمليات المسموح بها على مورد أو ضمن سياق معين. |
| Capabilities | القدرات | وحدات امتياز تفصل بعض الصلاحيات الإدارية إلى عناصر يمكن ضبطها. |
| Namespace | فضاء أسماء | آلية تقدم للعمليات رؤية معزولة لمورد من موارد النظام، مثل معرّفات العمليات. |
| Shell | صدفة الأوامر | برنامج يفسر الأوامر ويوفر وسائل لتركيبها وتشغيلها. |
| Terminal | طرفية | واجهة لإدخال النص وعرضه؛ يمكن أن تعمل الصدفة داخلها. |
| Directory | دليل؛ مجلد | بنية تربط أسماء بملفات وأدلة أخرى ضمن شجرة نظام الملفات. |
| Log | سجل | رسائل أو بيانات تسجل أحداثًا للمراقبة والتشخيص. |

## فروق تستحق بطاقة تذكير

- **العملية ليست البرنامج:** يمكن أن ينتج تشغيل البرنامج نفسه عدة عمليات.
- **النواة ليست نواة المعالج:** الأولى برمجيات إدارة، والثانية عتاد تنفيذ.
- **فضاء المستخدم ليس حساب المستخدم:** الأول بيئة تنفيذ، والثاني هوية وصلاحيات.
- **المستخدم `root` ليس الدليل `/`:** الأول حساب، والثاني جذر شجرة الملفات.
- **الذاكرة الافتراضية ليست المبادلة:** يمكن أن توجد الأولى من دون تفعيل الثانية.
- **نداء النظام ليس أمر الصدفة:** قد يستخدم أمر واحد نداءات نظام كثيرة أثناء تنفيذه.
- **`fork` ليس `exec`:** الأول ينشئ عملية، والثاني يستبدل برنامج عملية موجودة.
